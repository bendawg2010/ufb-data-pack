# University Football data pack

This is the required teams-and-rosters pack for University Football.

## Install

1. Click **Code**, then **Download ZIP**.
2. Extract the downloaded zip.
3. Open University Football in Chrome or Edge.
4. Click **Load Required Datapack** and choose the extracted folder.

The browser reads the files locally and stores them in IndexedDB. Nothing is uploaded.
The game also supports an optional `audio/` folder for locally owned stadium music.
Place MP3, M4A, OGG, or WAV files there before importing. A track with `Still Fly`
in its filename is used for menu music; team-named fight songs are matched to scoring
and home-defense third-down events.
